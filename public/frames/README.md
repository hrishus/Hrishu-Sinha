# Frame Sequence Upload Directory

Drop your exported video frames / sequence here so they can be smoothly animated as the visitor scrolls through the portfolio.

## Supported Formats & Naming:
You can name your images using any standard sequential format:
- `frame_0001.jpg`, `frame_0002.jpg`, ... up to `frame_0144.jpg` (or `.png`)
- `frame_001.jpg`, `frame_002.jpg`, ...
- `1.jpg`, `2.jpg`, ...
- Or simply upload the whole folder directly in the UI using the **Visual Editor Drawer** (`Ctrl + E` -> Animation tab -> **"Select Frames Folder"**).

The canvas will automatically detect the aspect ratio, center it, apply smooth inertial scroll scrub, and layer interactive ambient lighting and cursor parallax!
